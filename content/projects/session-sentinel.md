# session-sentinel

`status: active`

[open the repository](https://github.com/v01dF0rg3/session-sentinel)

A Manifest V3 Chrome extension that ends web sessions on demand, after inactivity,
when the screen locks, or when the browser closes.

## What stands out

- Reports the difference between a server-side sign-out, local data clearing, and a failed step.
- Uses a setup gate so automatic triggers never fire before they are configured.
- Includes diagnostics and an activity log for checking what actually happened.
- Keeps observed site data local — no account, telemetry, or analytics.
